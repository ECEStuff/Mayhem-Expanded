Локализация Azimuth

По умолчанию используется английский язык. Переключиться можно в любой момент через меню
Справка > Язык > English / Русский.

Главное окно переводится сразу без перезапуска и сброса галактики.
Открытые модальные окна (Сохранение/Загрузка, Конфигурация, Редактор секторов, Корабли и вооружение)
завершают работу перед возвратом в меню Справка > Язык; вновь открываемые окна используют
выбранный язык.

Ваш выбор сохраняется для каждой установки Azimuth в файле Settings.txt в виде
UiLanguage|44 или UiLanguage|07 и восстанавливается при следующем запуске.

Файл Localizations.json содержит необязательные пользовательские замены для английского 
языка и остаётся английским каталог релиза. Файл Localizations/Localizations_Russian07.json 
содержит русские переводы; отсутствующие ключи берутся из английского варианта.
Редактор конфигурации при русском интерфейсе использует ConfigDefaults/SettingNames_07.json.
Файлы HelpMain_07.txt и ReleaseNotes_07.txt также используются на этом языке.

Важно: язык интерфейса Azimuth не зависит от языка X3, используемого
для создаваемых файлов ресурсов addon/t и addon/mov. Язык игровых файлов
сохраняется из конфигурации установки на момент запуска. Смена языка
интерфейса не переименовывает и не изменяет файлы ресурсов галактики.

Старые версии программы, в которых русский файл перевода перезаписывал
Localizations.json, будут работать в таком виде, пока вы не сохраните выбор языка в настройках.
После переключения на английский язык при удобном случае верните исходный английский
файл Localizations.json на место, чтобы избежать путаницы в файлах.
