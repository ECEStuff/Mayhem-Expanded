- The bail chance multiplier is now capped between 0-100% in order to prevent bailing exploits.

  - This fixes Kha'ak interceptors having the same bail chances as Kha'ak fighters on insane mode.
  - It also normalizes capital ships to have halved bail chances (rather than -33% bail chance) on insane mode, ensuring that the bail chance penalty on insane mode is properly applied.
