The Discovery Update has arrived!
Plenty of new encounters across the galaxy await your discovery. The mod has been updated to 2.1. 

Previous savegames compatibility: PARTIAL*. 
Previous galaxies compatibility: YES.

*Notes:
- Starting Xenon balance changes and Pirate Base spawning changes apply only to new games.

- New Kha'ak quest.
- Reworked Pirate Base spawning and placement for greater variety and reliability.
- Rebalanced starting Xenon defenders. Increased M3 defenders for newly built Xenon stations.

-----------------------------------------
		CHANGES
-----------------------------------------
- Reworked Pirate Base (PB) spawning:
  - PBs now spawn within a 3D outer shell instead of 1 of 4 corner regions in a sector.
    - Placement is constrained to remain far from the sector center while keeping each axis within safe sector bounds.
    - This prevents rare cases where PBs could immediately be destroyed after spawning too close to large planets while the player is in-sector.
  - New PBs now spawn more than 5 jumps away from Pirate Havens (PBs and Yaki Outposts).
    - This distributes PBs more evenly across the galaxy while allowing Yaki Outposts to act as a source for PB regeneration.
  - Initial galaxy generation and PB respawning now use the same spawning logic.
    - This ensures both systems use the same placement and initialization behavior.

- Rebalanced starting Xenon defenders:
  - This rebalance is due to an interaction between Xenon stations and extra Xenon garrisons, the Xenon ships spawned every 3 hours.
    - The game picks the closest Xenon station relative to the OCV portal in order to spawn a Xenon garrison. On higher difficulties, this results in spawning more garrisons closer to the portal and to the point where a sector becomes a no-fly zone.
    - By reducing the number of stations, the game can spawn garrisons in more sectors without overpopulating the other sectors.
    - This rebalance redistributes Xenon presence while strengthening individual Xenon station defenses by difficulty.
  - Starting Xenon station density decreased as follows:
    - Easy: 1 station (unchanged)
    - Normal: 1.5 stations -> 1.25 stations
    - Hard: 2 stations -> 1.5 stations
    - Insane: 2.5 stations -> 2 stations
  - Starting Xenon station defenders were redistributed and strengthened by difficulty to compensate for the reduced station density.
    - Easy: 
      - 3-20 LX -> 10-13 LX
      - 2-8 P -> 4-6 P
      - Capital chances unchanged (50% to spawn M7, 25% to spawn M2)
    - Normal:
      - 3-20 LX -> 12-16 LX
      - 2-8 P -> 5-7 P
      - M7 chance: 50% -> 60%
      - M2 chance: 25% -> 30%
    - Hard:
      - 3-20 LX -> 12-18 LX
      - 2-8 P -> 6-8 P
      - M7 chance: 50% -> 75%
      - M2 chance: 25% -> 37.5%
    - Insane:
      - 3-20 LX -> 12-18 LX (same as hard)
      - 2-8 P -> 6-8 P (same as hard)
      - M7 chance: 50% -> 100%
      - M2 chance: 25% -> 50%
   - Added J to M7 pool and Z to M2 pool. 
     - This adds elite encounters to the pool. Previously, the game selected a standard and an improved ship from the pool.
     - These ships spawn with support ships.
     - Each pool now has the following chances to choose a ship type:
       - M7: 50% Q, 30% C, 20% J
       - M2: 50% K, 25% I, 25% Z
- Adjusted new Xenon M3 defenders for consistency. 
  - These are Xenon defenders homebased to Xenon Stations built in newly conquered Xenon sectors.
  - Increased LX count:
    - Easy: 8 -> 10
    - Normal: 10 -> 12
    - Hard: 15 -> 18
    - Insane: 20 -> 24 (10 -> 12 if player joined OCV)
