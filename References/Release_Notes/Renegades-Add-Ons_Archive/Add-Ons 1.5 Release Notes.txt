Happy new year! Due to potential save incompatibility, the mod has been updated to 1.5 rather than to 1.4.26.

A NEW GAME is required if your save already contains existing Jump Stations. Saves without existing Jump Stations are safe to continue.

		ADDITIONS
-----------------------------------------
- (1.5.6) Additions
  - Added alternative way to start the OCV plot.
    - Updated OCV mission objective. Changed from "build an OCV ship (optional)" to "Begin integrating OCV technology."
    - Hint: Early OCV progression is now more reactive to player behavior, not just construction choices.

  - If you don't have infamy, boarding a Xenon capital ship will now give you loyalty points to the sector owner, if that owner is an NPC faction.
