The mod has been updated to 1.7.5. Starting with this version, each update will have its own set of patch notes rather than one large cumulative set of release notes.

This version is compatible with existing versions.

-----------------------------------------
		ADDITIONS
-----------------------------------------
- Added Development sub-folder to the repo. It contains instructions for those who wish to get started on X3AP modding.

-----------------------------------------
		CHANGES
-----------------------------------------
- Tugs now respect Outpost jump range. Explorers are unchanged.
- Player's advanced satellite factories now have their jump range set to 9. This is for parity with the AI.
  - This jump range is overridden by explorers - their maximum jump range is 15.

	. Mayhem.Task.Worker.Tug.xml
	. Mayhem.GetReachableExplorerSectors.xml
	. Mayhem.InitializeFactorySettings.xml

		FIXES
-----------------------------------------
- Fixed debug messages being displayed.

	. Mayhem.IsClaimable.xml

- Fixed ship copying curing the OCV virus from non-OCV ships. Non-OCV ships get the OCV virus if they are built during the terraformer virus Outpost event.
  - CopyShip is supposed to copy all states from the existing ship to the new ship.
