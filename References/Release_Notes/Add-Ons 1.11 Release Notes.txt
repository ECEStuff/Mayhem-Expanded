Emerging powers, better expansion! The mod has been updated to 1.11. 

Previous savegames compatibility: PARTIAL.
- A new game is not required but recommended if you've already spawned in the Yaki (and/or Phanon if you've already joined the OCV).
  - The main reason is that Yaki and Phanon arrival (OCV plot branch) start with more cohesion. 
  - This fixes a problem where Yaki fleets were getting picked off because they had to fly through hostile space to reach their isolated sectors.
 
Previous galaxies compatibility: YES.

  - When joining the OCV and Phanon either arrives or needs extra territory, they gain sectors as follows:
    - 1. If they don't have any sectors, then they choose a starting point (same as how Yaki arrive).
    - 2. If they have existing sectors, then they choose a starting point that is at least 4 jumps away from any Phanon sector.
    - 3. Conquer the starting point and up to 1 (2 on galaxies with 100+ sectors) adjacent sectors.
    - 4. Repeat steps 1-3 until they have 6 sectors or 8% (previously 6%) of the galaxy, whichever is greater.
    - Note: Unlike Yaki who conquer until they form one large cluster, Phanon operates with multiple isolated territories. 
      - This fits their preference as stated during the Phanon plot branch.

  - There are now 2 checks with unknown sectors; previously there was only one.
    - The first check is largely the same as before. For reference:
      - 1. Get all neighbors, if any.
      - 2. If there are no neighbors, then do as follows:
        - (New) On insane, check for the nearest commonwealth sector within 3 jumps away. 
          - If found, give to the nearest commonwealth faction.
          - If not, any isolated unknown sectors caught at this check are deferred to a second check.
        - On hard, skip and move to the next unknown sector.
      - 3. If there are neighbors, assign as follows:
        - If there is a nearby cluster (commonwealth or Xenon), give to a random cluster.
        - If there are no clusters, give to a random neighbor.
    - The second check is only on insane mode. It repeats steps 1-3, but this time any truly isolated sectors will go to the Xenon.

-----------------------------------------
		FIXES
-----------------------------------------
- Fixed clustering algorithm not properly checking for clusters.
  - In layman's terms, it was checking only up to 2 jumps and could even check sector A itself. It was considering a pair of sectors as a cluster.
  - More specifically, the original IsBorderWithCluster was checking if the specified sector (sector A) borders a cluster as follows:
    - Check adjacent sectors.
    - From those adjacent sectors, check if their adjacent sectors match the same owner sector A's adjacent sectors.
  - Now, the algorithm will continuously check up to N jumps away until at least 3 sectors (minimum cluster size) under the same ownership are found connected to each other.
